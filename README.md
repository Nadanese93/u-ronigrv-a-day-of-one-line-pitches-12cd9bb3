# A Day of One-Line Pitches

This entry is a single one-sentence pitch for a friend who has never coded: you've been carrying that app idea for months, so describe it in plain words to an AI agent on make.fun tonight and you'll tap through a working version before bed, free to try, with the idea staying yours. The program `main.ts` writes that exact sentence to `/output/entry.txt`.
